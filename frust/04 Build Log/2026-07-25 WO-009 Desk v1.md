# Build Log — WO-009: Desk v1

`frust-proto` graduated: a metadata-driven Desk a Frappe user would recognize, speaking ONLY the kernel REST surface under session tokens. Fully server-rendered — no asset bundle, no client runtime, zero signals (the v1 field set has no dependent fields, so nothing earns client-side logic under ADR-007). The stack is left running for a hands-on click-through: kernel `frust serve` on :8790, Desk on :3000 (`manager`/`pw-manager`, `clerk1`/`pw-clerk1`).

## Kernel additions (all behind the same one permission compiler)

- **Sessions**: `/login` (DB-derived role, `rand::string(64)` token, session record stores the SurrealDB JWT so restarts re-hydrate the token cache), `/logout`, bearer resolution on every data route. 401 is its own status; the header trio is gone from the codebase.
- **New routes**: `GET /meta`, `GET /meta/{dt}`, `POST /doctype` (manager; validates the metadata shape BEFORE storing, then runs the sync engine — criterion 6's no-restart), `GET /audit/{dt}/{key}` (manager), `GET /lag/{rollup}`.
- **Two broker hardenings found by building the UI on it:**
  1. **Hook output is now bounded by the metadata envelope** — the toy hooks inject `total` into every doc; a customer create bounced off SCHEMAFULL. A hook can no longer invent fields the DocType doesn't declare.
  2. **`docstatus` joined `ENGINE_FIELDS`** — it was writable but not readable through the envelope; the Desk literally could not see lifecycle state. The floor is now visible wherever it exists.
- surql-monopoly allowlist ruling recorded for rest.rs (idents checked, tokens charset-validated + escaped).

## The Slow-4G line (620 ms governs; report per screen)

Every screen is ONE self-contained HTML document — zero subresources, no JS, no CSS files. Loopback server medians (9 samples): home 11.8 ms · list+filter 12.2 · form 14.1 · doc 13.0 · report(T1) 13.4 · report(T2+lag) 13.8 · audit 11.8. Navigations cost 1 round-trip; POST actions cost 2 (303 See Other, deliberately — a 307 replays the POST). Worst case under Slow-4G ≈ 2×RTT + ~14 ms server + one small transfer — **every v1 screen holds the line with wide margin; nothing to report over budget.** List refresh is a 60 s meta-refresh (REQ-6.5.2 polling path; no socket layer).

## Findings

1. **Tier-2 scripting decimal footgun (user-facing doc material for ADR-007):** decimals reach scripts as STRINGS; `doc.total + tax` is string concatenation → NaN → the field silently became null and vanished. The demo script now models the discipline: `Number()` in, same-type-as-input out. The script-engine shell's type re-imposition held throughout — the bug was authored, not structural.
2. **Topcoat `redirect()` is 307** — replays POST against a GET route (405). POST handlers use `see_other` (303) + a one-shot flash cookie for friendly errors. Also: a `#[page]` GET and `#[route]` POST cannot share one path.
3. **The engine's destructive gate fired during demo seeding** — reshaping already-synced rollup tables into write-closed form means field REMOVEs, refused by default. Correct behavior; the operator resolution (drop empty tables, re-sync) is the documented path. Seeding order that avoids it: declare aggregates before first sync of their rollups.
4. Churn-degradation caveat confirmed twice more (release gate 30 ms on a churned instance → 23/24/23 after restart). The caveat is earning its keep.

## v1 boundaries kept + disclosed gaps

- Topcoat pinned (local-dev); **no topcoat-session** (that's Topcoat auth — 🚫 bucket): the kernel owns sessions, the Desk carries an opaque HttpOnly cookie via topcoat-cookie. No spreadsheet grids; polling not sockets.
- `allow_on_submit` is UI-enforced; the DB lattice enforces transitions and resurrection, not per-field edits at ds 1 — a field-level DB guard is future work if the threat model demands it.
- Session lifetime = the SurrealDB token TTL (1 h), no sliding refresh; expiry surfaces as "log in again".
- Desk keeps the proto's blocking-ureq-in-async shortcut (loopback kernel; disclosed since WO-002).
- Desk changes live on the Topcoat clone's `local-dev` branch (workspace member), uncommitted pending a PM call on where Desk source should permanently live — it has outgrown "example".
